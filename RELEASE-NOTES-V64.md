# Fabio Ecosystem v64 — LERNWERK Editorial Grammar Review

## Scope
- Editorial review of all 140 grammar lessons across German, English, French, Spanish, Italian, Russian and Portuguese.
- 20 lessons per language, A1–C1 oriented progression.

## Improvements
- Replaced generic explanation blocks with topic-specific guidance.
- Added lesson-specific formation/usage notes.
- Added a concrete typical-error warning to every lesson.
- Reworked transfer tasks so learners actively produce language instead of only recognizing rules.
- Replaced the two generic strategy quiz questions in every lesson with grammar-topic-specific questions.
- Added an editorial-review marker in the lesson modal and on every language page.
- Added a transparent note that CEFR labels are a didactic progression and not an official CEFR assessment.

## Specific corrections / refinements
- Russian motion-verb rule no longer contains mixed German wording.
- Russian instrumental-case rule rewritten fully in Russian.
- Portuguese `há` rule rewritten fully in Portuguese and clarified as invariant.
- Spanish `hay` rule rewritten fully in Spanish and clarified as invariant.
- Italian equality comparison example improved to `È tanto utile quanto l'altro.`
- Spanish advanced connector example changed to `Aunque sea difícil, continúo.` to illustrate an authentic subjunctive context.
- Portuguese learner notes explicitly distinguish European Portuguese (PT-PT) pronoun placement from Brazilian usage.
- Spanish Present Perfect notes now flag regional Spain/Latin America differences.
- French, Italian, Spanish and Portuguese conditional clauses now explicitly warn against using conditional/future in the `si/se` clause where standard grammar does not allow it.
- Russian aspect, motion verbs and case explanations now include more precise usage distinctions.

## Content standard
The lesson content is designed as teaching material and has been editorially reviewed for internal consistency and practical learner guidance. It is not an official CEFR certification curriculum.
